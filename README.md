# MadMaxxing

A multiplayer first-person shooter made in Unity using the Entity Component System (DOTS) and Netcode for Entities.

**Features**
- Online multiplayer with session codes, direct connect, and a dedicated server build
- First-person character controller, health, death, and respawning
- Several weapon types (machine gun, laser, plasma, rocket) with visual effects
- Main menu, pause menu, loading screen, and respawn screen
- Mobile touch controls

**Built with:** Unity 6 (6000.2.13f1), C#, Entities, Netcode for Entities, Input System
